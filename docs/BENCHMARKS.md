# Interaction Benchmark Note

Rechecked against current public versions on 2026-08-12.

## Neal.fun — Asteroid Launcher

Borrowed: immediate target placement, a tiny understandable primary parameter set, and fast cause/effect experimentation.

Rejected: flat-map primacy and concentric damage circles as the main experience.

Canonical site: https://neal.fun/asteroid-launcher/

## Earth Impact Effects Program

Borrowed: explicit projectile diameter, density, velocity, angle, target awareness, and separation of consequence families.

Rejected: calculator-first hierarchy and text-dominant output as the default experience.

Canonical site: https://impact.ese.ic.ac.uk/ImpactEarth/ImpactEffects/

## NASA Eyes

Borrowed: direct 3D camera manipulation, free-roam/ride-along grammar and user-controlled time travel.

Rejected: persistent mission-browser information-card density.

Canonical site: https://eyes.nasa.gov/

## earth.nullschool

Borrowed: a continuously manipulable globe, moving global fields and transient time control.

Rejected: persistent menu density and the idea of the impact as merely another overlay.

Canonical site: https://earth.nullschool.net/

## Synthesis

The governing pattern is: immediate manipulation first, model discipline underneath, free camera and reversible time throughout, and animated global fields only when they clarify the catastrophe itself.
